# Executor Apps

**Spend less time gathering information and more time deciding what to do with it.**

This is a collection of small, self-contained apps for [Executor](https://executor.sh). Each app takes on a repeatable part of a workflow—finding information, organizing it, or saving it for the next step—so you and your agents can focus on the work that needs judgment.

## App catalog

| App | What it does | Install with an agent |
| --- | --- | --- |
| [Radar News](apps/radar-news/) | Collects AI, Brazilian automotive, and Apple news for an editorial workflow. | [Installation skill](apps/radar-news/SKILL.md) |

## Get started

Pick an app and give your Executor-connected agent its `SKILL.md` from a repository revision you trust. Each skill explains what to deploy, how to connect your own provider accounts, and how to verify the installation. Or start with the app’s README if you prefer to set it up yourself.

The source is public; your deployed app, provider credentials, and collected data are separate. Enter keys only in Executor’s secure connection form. Review provider costs before running a live test or enabling a schedule.
